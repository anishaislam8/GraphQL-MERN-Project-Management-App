# Project Management System Using MERN Stack and GraphQL

## Description
This is a project management system built with the MERN stack: MongoDB, Express.js, React.js, and Node.js, along with GraphQL. It allows users to create, manage, and track projects in an organized way. Users can add clients and assign projects to them, making it easier to manage multiple relationships. The app supports full CRUD operations for projects, with GraphQL handling data fetching and updates. The frontend is developed using React, while the backend is built with Node.js and Express. All project and client data is stored in MongoDB.

## How to Run the Project

Run `npm install` in both the client and root directories to install the required dependencies.
    
Then, run the following commands in separate terminal windows:

    ```
    # In the root directory (backend)
    npm start
    ```

    ```
    # In the client directory (frontend)
    npm start
    ```
